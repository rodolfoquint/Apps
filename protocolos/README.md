# Protocolos · Renova · Imagenología de Longevidad

Procedimientos operativos estandarizados para el **Mapeo de Trayectoria Biológica** — la evaluación con ultrasonido de alta resolución que mide e interpreta el cuerpo como un sistema en evolución a través del tiempo.

## Documentos

- [`protocolo-ultrasonido-longevidad.md`](protocolo-ultrasonido-longevidad.md) — Protocolo de adquisición estandarizada del estudio completo (8 sistemas), con técnica, planos, mediciones, valores de referencia y reglas de reproducibilidad longitudinal.

El protocolo está diseñado para producir las mediciones cuantitativas del Reporte de Imagenología de Longevidad de forma **reproducible entre estudios**, condición indispensable para construir una trayectoria biológica válida.
